# CV Application

A simple React project for building a professional CV/resume application. This app was created as part of The Odin Project curriculum and is designed to help me
 practice React fundamentals while creating a polished resume builder.

## Features

- Input personal information, education, and work experience
- Live preview of the CV in a clean layout
- Simple and reusable React component structure
- Responsive resume design
- Easy to customize and extend

## Tech Stack

- React
- Vite
- CSS

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open the local URL shown in the terminal to view the app

## Project Structure

```bash
src/
  components/
  App.jsx
  main.jsx
  styles/
```

## Usage

Edit the form fields to add your name, contact details, education, and work history. The app updates the CV preview automatically so you can see your resume as you build it.

## Notes

This is a beginner-friendly project focused on learning React state, components, and UI composition. You can continue improving it by adding features like print-to-PDF, theme changes, or a dark mode.
